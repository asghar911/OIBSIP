# EDA on Retail Sales Data

**Track:** Data Analytics | **Level 1 - Task 1**

## Objective
Exploratory Data Analysis on a retail sales dataset to uncover sales trends, customer behaviour and product performance.

## Tools
Python, pandas, matplotlib, seaborn, Jupyter Notebook

## Contents
- `retail_sales_dataset.ipynb` - the analysis notebook
- Dataset (CSV) - source data
- `screenshots/` - key charts

## Key Steps
- Data inspection and cleaning
- Descriptive statistics
- Time series sales trends
- Customer demographics and product analysis
- Correlation heatmap
- Business recommendations
