# House Price Prediction using Linear Regression

**Track:** Data Analytics | **Level 2 - Task 1**

## Objective
Build and evaluate a Linear Regression model that predicts house prices from features such as area, bedrooms, bathrooms, floors, age, location, condition and garage.

## Dataset
House price dataset with 2000 records and 10 columns (no missing values).

## Tools
Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook

## Contents
- `house_prices.ipynb` - the analysis notebook
- `house_prices.csv` - dataset
- `screenshots/` - key charts

## Key Steps
- EDA: null check, descriptive statistics, price distribution
- Feature selection discussion and One-Hot Encoding
- Correlation heatmap
- 80/20 train-test split
- Linear Regression model
- Evaluation: MSE, RMSE, R2
- Actual vs predicted plot and residual plot
- Coefficient analysis
- Bonus: Ridge and Lasso comparison
